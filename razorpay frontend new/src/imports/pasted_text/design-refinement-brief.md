==================================================
3. COLOR SYSTEM
==================================================

Keep the dark theme.

However:

- reduce saturated cyan
- reduce purple
- reduce glowing accents
- reduce excessive red/amber glow
- use neutral dark surfaces as the dominant visual language
- use accent colors primarily for interaction and semantic status

Cyan/blue:
Use mainly for interactive/selected states and important navigation.

Purple:
Use very sparingly for AI-generated explanation/provenance.

Green:
Use for successful/verified states.

Amber:
Use for warnings, projected/simulation states, and approval attention.

Red:
Use only for genuine critical/blocking conditions.

Do NOT make the interface glow.

Colors should feel like financial-status semantics,
not decorative neon.

==================================================
4. TYPOGRAPHY
==================================================

Reduce the amount of terminal/monospace styling.

Keep monospace only for:

- IDs
- fingerprints
- timestamps where appropriate
- technical metadata
- audit/event identifiers
- system-level metadata

Use a clean modern sans-serif for:

- page titles
- section titles
- important numbers
- recommendations
- explanatory text
- buttons
- business metrics

Main UI should feel like premium fintech software,
not a terminal.

Small uppercase technical labels may remain,

Do NOT make every section look like a command-line interface.
